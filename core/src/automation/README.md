# core/src/automation: Automations

Events from the decoders (catalog.cpp), the condition language (expr.cpp), rules and recipe files (rules.cpp, json_mini.cpp), the engine with its thread and limits (engine.cpp), the Lua sandbox (script.cpp) and the built-in recipes (recipes.cpp). Built as the small library dect2_automation so its test needs no receivers. See docs/automations.md.
