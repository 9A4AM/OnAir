# core/src/net: Networking

Sources for this topic. Remote-control API server, rtl_tcp share server, network tuner and network radio, the TCP client and socket compatibility layer, data feeds (SBS, Beast, AIVDM ...), PSKReporter and WSPRnet reporting.

Mode folders (core/src/<mode>/) hold one decoder each; this folder holds code shared by all of them. See ARCHITECTURE.md.
