# core/include/dect2/tv: Transport streams and the TV player

Public headers (#include "dect2/tv/<name>.h") for this topic. MPEG-TS parsing, recording and output (ts, ts_record, tsout), the player (FFmpeg), concealment, HLS, subtitles, teletext, elementary-stream saving and the demo stream.

Mode folders (core/src/<mode>/) hold one decoder each; this folder holds code shared by all of them. See ARCHITECTURE.md.
