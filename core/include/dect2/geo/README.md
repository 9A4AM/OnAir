# core/include/dect2/geo: Maps and geography

Public headers (#include "dect2/geo/<name>.h") for this topic. Maidenhead locators, satellite passes, map layers, tile cache, MBTiles reader, the coarse world outline and the range plot.

Mode folders (core/src/<mode>/) hold one decoder each; this folder holds code shared by all of them. See ARCHITECTURE.md.
