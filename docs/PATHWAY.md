## 2026-10-18 FSQ and IFKP
Two separate new modes: FSQ (family 113, active 114, std 115; five speeds, directed messages with sender, addressee, command, CRC of the callsign) and IFKP (family 116, active 117, std 118; three speeds). One shared 33-tone receiver (core/src/fsq/kbd33.cpp: band search, tone grid, running sums of 73 positions, speed and timing from the sums, history decode on lock), a shared station and generator, two thin receivers, one UI template. Synthetic tests only; parameters and varicode from fldigi's sources, not checked against a real transmitter.

## 2026-10-19 KAPP burst PHY and selective repeat
Branch kapp-028. New mode directory kapp (core/src/kapp, core/include/dect2/kapp, tests/kapp): burst builder (profiles 0-8, preamble of two Zadoff-Chu halves, 4x repeated header, LDPC blocks with CRC-16, pilots, RRC at 8 samples per symbol), streaming BurstReceiver (per-half preamble correlation, fractional timing, CFO from the halves then from the 942 known symbols, pilot tracking), ArqSender/ArqReceiver (each PHY block carries its message offset, so resends work at any profile), ProfileController, ACK burst, resampler. Written against the kris foundation API (kris_fec.h, kris_common.h); not built or run on the laptop, CI to check. Additions to the spec: fixed scrambler on coded bits, flag bit 3 marks an ACK burst, message-offset blocks instead of the 10-bit retransmit table.
