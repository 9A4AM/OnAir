## 2026-10-19 KAAL streaming voice receiver in C++
Branch kaal-rx-028 (merged kaal-phy-028 and kaal-codec-028; the two golden headers are now kaal_golden.h (PHY) and kaal_golden_codec.h (codec)). core/src/kaal/kaal_rx.cpp, core/include/dect2/kaal/kaal_rx.h: dect2::kaal::VoiceRx, a chunked port of kaal_rx.py. The first 3 s gather the static parameters as in the Python (DC, FFT sweep correlation and per-period gain fit, matched filter, symbol-clock fit, preamble differential sync, CFO, fine slope); then the stream is replayed and run frame by frame: sweep removed per period with a small PLL on the period position, early-late check on the preamble for the symbol clock (not in the Python), per-frame gain fit and noise estimate mixed 50/50 with the running mean, max-log demap, deinterleave per 4-frame block (block offset from the syndrome score of the first 27 frames), LDPC, codec. KaalCodec::StreamDecoder added so the codec runs frame by frame with the same state as decode(). Tests: tests/kaal/test_kaal_rx_loopback.cpp (bit-exact clean, FER at 8 dB, +-200 Hz, mid-stream start) with a test transmitter in kaal_rx_gen.h. Not built or run on this Mac; CI will.

## 2026-10-19 HFDL shared FFT channeliser for 32 and 64 MHz captures
Branch hfdl-channeliser-028 (0.2.8 + hfdl-opt-028 + hfdl-fast-028). Above 16.5 MHz with at least 4 channels in band, HfdlReceiver runs one weighted-overlap-add filter bank (N bins of 32-64 kHz, 4N-tap Kaiser prototype, hop N/2, sub-band rate 2 rate/N) on the analysis thread and each channel takes the nearest bin plus a residual mixer at the sub-band rate; cost ~ input rate, not rate x channels. Up to 16 MHz the per-channel path is unchanged. Not run on this machine (CI): tests hfdl_speed (16/32/64 MHz, old vs new at 32 MHz) and hfdl_chan (3 bursts in a 32 MHz capture, same frame count as the old path).
## 2026-10-19 TETRA voice: traffic-channel decoding and per-call encryption check

Traffic channel decoder from the public ETSI EN 300 395-2 V1.3.1 clause 5.5: descrambling, the (24,18) matrix deinterleaver (the old a = 103 guess is gone), depuncturing (2/3 and 8/18), Viterbi of the 16-state rate 1/3 code, CRC-7 plus parity check, table 5 re-ordering into two 137 bit speech frames for the user-installed plug-in (core/src/tetra/tetra_traffic.cpp).
