## 2026-10-19 KAVB physical layer and video container
Branch kavb-028. New mode directory kavb (core/src/kavb, core/include/dect2/kavb, tests/kavb); `kavb` appended to the single DECT2_MODES line, not yet wired into the app mode table (the integration step does that). PHY (kavb_phy, kavb_rx): profiles A to D (700 / 1050 / 1400 / 1400 ksym/s, 16-QAM, 64-QAM for D, LDPC n = 1920 rate 3/4) plus a robust QPSK rate 1/2 flag, 32-symbol Zadoff-Chu preamble, 64-bit header (profile, robust, FEC profile, sweep index, sequence, link quality, CRC-16) on a K = 7 rate 1/2 code, pilot every 16th symbol, pseudo-random bit interleaver across the 4 blocks of a frame, RRC 0.25 at 4 samples per symbol, V-shaped sweep at -10 dB (period = whole frames, about 0.5 s). Receiver: matched filter, split-preamble correlation, header decoded over a grid of residual frequencies (the sweep makes a closed-form estimate too noisy), maximum-likelihood pilot/preamble fit for frequency, phase and amplitude, sweep estimated per quarter frame and subtracted before a second matched-filter pass, max-log demapper, decision-directed 7-tap equaliser pass for multipath. Video/audio layer (kavb_av): packets (type, stream, seq, length, CRC-32), cells of one LDPC block, FEC groups with a GF(256) erasure code (new Rust module rust/onair_kris/src/erasure.rs, two new C ABI functions in rs/kris.h), fragmentation of codec units, pluggable PayloadSource / PayloadSink (no codec in the repo), synthetic AV source, bit budget per profile. Measured thresholds and what is not verified: see KAVB-MEASURED-v0.1.md.
